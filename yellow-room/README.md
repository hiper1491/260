# 黃色小屋（Yellow Room）- 收穫與指引

## 🌟 系統概述

**黃色小屋**是 260 卓爾金曆神廟系統的「收穫空間」，專注於為使用者提供針對特定生活領域的指引與落地建議。

### 核心定位
- **能量屬性**：收穫（Ripen）、豐盛、智慧、落地
- **功能定位**：針對特定生活領域，獲取專屬的印記指引與實踐建議
- **視覺氛圍**：金黃色系、陽光、溫暖、成熟

## 🔄 使用流程

### 1. 主題選擇（index.html）
- 使用者進入黃色小屋
- 看到五個主題按鈕
- 點擊選擇感興趣的領域
- 選擇後進入指引頁面

### 2. 深呼吸引導（guidance.html）
- 顯示主題標籤
- 呼吸圓圈動畫（4秒循環）
- 引導文字："請深呼吸，讓心沉靜下來"
- 準備好後點擊「獲取指引」按鈕

### 3. 純亂數抽牌
- 系統隨機抽取 1-260 之間的 KIN
- **不預篩**、**不依主題過濾**
- 確保共時性（Synchronicity）的真實性

### 4. 指引顯示
顯示內容包含：

#### a. KIN 資訊卡
- KIN 編號
- 調性 + 圖騰名稱（如：磁性的紅龍）
- 圖騰圖片

#### b. 共時訊息
- 今日整體引導訊息

#### c. **調頻建議**（放大顯示）
- 心態調整、意識層面的建議
- 金色漸層背景強調

#### d. **落地行動**（放大顯示）
- 具體可執行的實體行動
- 金色漸層背景強調

#### e. 智慧金句
- 根據選擇的主題
- 隨機顯示相關智慧語錄
- 斜體、淺色背景

### 5. 歷史紀錄
- 保留最近 5 次抽牌記錄
- 每筆記錄標註：
  - 日期
  - 主題標籤
  - KIN 編號
  - 調性 + 圖騰描述

## ✨ 核心理念

### Alignment vs Grounding

**Alignment（調頻建議）**
- 意識層面的調整
- 心態、視角、覺察
- "如何看待"

**Grounding（落地行動）**
- 物質層面的實踐
- 具體、可執行、可觀察
- "如何行動"

### 範例對照

**KIN 1 磁性的紅龍**
- **Alignment**: "做一件最簡單的滋養：好好吃一餐／補水／提早睡"
- **Grounding**: "準備一份簡單但你真正想吃的食物；吃的時候不滑手機，專心進食"

## 📝 維護說明

### 更新智慧金句
編輯 `guidance.html` 中的 `wisdomQuotes` 物件：

```javascript
const wisdomQuotes = {
  financial: [
    "新的財務智慧語錄...",
    // 更多語錄
  ]
};
```

### 更新主題
如需新增主題，需修改：
1. `index.html` - 新增主題按鈕
2. `guidance.html` - 更新 `wisdomQuotes` 和 `themeNames`

### 更新 kinData
如需更新 260 個 KIN 的內容，編輯 `kinData.js`：
- 確保每筆資料包含完整欄位
- 特別注意 `alignment` 和 `grounding` 的區別
