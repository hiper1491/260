## 🎨 文案範本

如果你想自己改寫文案，參考以下結構：

### 調頻建議範本（心態層面）
```
[做什麼/如何看待] + [為什麼有效]

例：
"開口前先深呼吸三次；用一句『我在意的是____』說重點，先不要急著解釋。"

分析：
- 前半句（行動）：開口前深呼吸三次
- 後半句（精神）：簡化表達，信任對方能理解
```

### 落地行動範本（身體層面）
```
[具體行動] + [可量測的時間/數量]

例：
"走到戶外或陽台，進行 5 分鐘深呼吸；回來後寫下一句感受。"

分析：
- 地點：戶外/陽台
- 活動：深呼吸
- 時間：5 分鐘
- 後續：寫下感受
```

### 智慧金句範本
```
[洞察] + [核心真理]

例：
"豐盛不是擁有很多，而是對現在有的真誠感謝。"

分析：
- 前半句（破除迷思）：豐盛不是擁有很多
- 後半句（新視角）：而是對現在有的真誠感謝
```

## 💡 設計建議

### 文案優化秘訣
1. **調頻建議** - 寫得越簡短越好（7-15 字）
2. **落地行動** - 具體到「可以今天就做」
3. **智慧金句** - 用比喻而不是說教
4. **時間感** - 提供「今天」的行動，不要「永遠」

### 色彩搭配建議
當前金褐系統很適合：
- ✅ 保持不變（已經很和諧）
- ⚠️ 改色系需要 6 處地方同步改
- 建議只改 `--gold-malt` 和 `--gold-amber` 兩個顏色

### 版面優化建議
- 調頻建議和落地行動現在是等權重，這個很好
- 智慧金句用斜體+淺背景，醒目但不搶戲
- 歷史牆放在最下面，不打斷主要內容
